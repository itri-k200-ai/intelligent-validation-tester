# 外部文件

其他團隊提供的串接文件。**原封不動放進來**，不要改寫 —— 這裡是「對方說了什麼」
的存證，我們自己的設計文件在 `docs/design/`。

| 子目錄 | 放什麼 |
| --- | --- |
| `後端規格/` | API 規格、資料欄位定義、序列圖、Postman collection 等 |
| `前端UI建議/` | 設計稿、切版建議、標註圖、Figma 匯出 |

## 命名建議

`YYYY-MM-DD_來源_主題.副檔名`，例如
`2026-08-27_RICtester_autoTest-v2.1欄位異動.pdf`。

日期是**拿到文件的日期**。同一份文件有新版就新增一個檔，不要覆蓋 ——
串接出問題時常常要回頭確認「當初拿到的是哪一版」。
