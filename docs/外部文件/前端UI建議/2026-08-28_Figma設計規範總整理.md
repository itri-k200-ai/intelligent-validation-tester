## 待確認事項

1. **字體**：Text Style 實際是 PingFang TC，說明頁寫 Noto Sans TC，需向設計師確認正式字體。
2. **Success 色**：CSS 色票為 `#80FFE8`，截圖標註為 `#72B6C9`。
3. **Item 圓角**：規範寫 14px，但按鈕 / 欄位實際為 32px @3x ≈ 11px。
4. **Secondary Button「下一步」Default 色**：截圖看起來是綠色，CSS 為 95% 白 + 綠色光暈；Hover 才是綠色。
5. **寬屏衛星地面設備驗測實驗室**：Figma 中 Disabled 與 Focused 兩個變體的樣式互換了（Disabled 有綠框、Focused 是 opacity 0.3），應為命名錯誤。
6. **Body Text Paragraph 在表格中的行高**：150%，與一般內文 130% 不同，為刻意設計。
